## Goal
Be comfortable with JavaScript before starting [Full Stack Open](https://fullstackopen.com).

## How this repo is organised
- One folder per article, named after it (`hello-world/`, `variables/`, ...)
- Each folder holds my solutions to that article's tasks
- `notes.md` holds short notes in my own words
- `projects/` will hold my plain JavaScript projects
